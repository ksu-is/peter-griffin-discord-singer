# Project Road Map
## Goal
I had a project from another class where I set up a very basic discord bot but I want to take that project to the next level.

## [RVC-discord](github.com/kindahex/RVC-discord) by kindahex
This repository will help us use a model to separate the vocals from the instruments and convert the vocals into a different voice.
I have verified that it does work and I will implement it into our discord bots code.

## [MusicBot](github.com/Just-Some-Bots/MusicBot) by Just-Some_Bots
This repository shows a basic music bot for discord. It just works and is very easy to set up.
I have tried it with my own Discord API code and it did work and I will use some elements of its code to make my discord bot work.
