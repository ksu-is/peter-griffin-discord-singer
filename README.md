# peter-griffin-discord-singer
Ever wanted Peter Griffin to sing to you in your Discord call with your friends? Now you can and it will run all locally!

## Process
I will use several different repositories like [discord.py](github.com/rapptz/discord.py) and [RVC-discord](github.com/kindahex/RVC-discord) to make the bot work.
It will convert any youtube link to an MP3 file so that RVC-discord can use it. Then, it will convert the vocals to sound like Peter Griffin and then send it back to discord to be played inside of a voice call.
